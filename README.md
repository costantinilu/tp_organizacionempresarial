# TP Organización Empresarial

## Integrante

Luciano Costantini

## Descripción

Este proyecto implementa un flujo de trabajo ágil utilizando GitHub, GitHub Flow, Jira y Google Colab para gestionar el desarrollo de un script de análisis de datos.

## Estructura del proyecto

5. Merge a la rama principal.

```text
├── datos/
├── scripts/
├── resultados/
├── README.md
└── .gitignore
```

## Tecnologías utilizadas

* Python
* Google Colab
* Git
* GitHub
* Jira

## Flujo de trabajo

1. Planificación de tareas en Jira.
2. Desarrollo en rama feature.
3. Commits asociados a tareas Jira.
4. Pull Request y revisión.
## Evidencias de trazabilidad

| Tarea Jira | Descripción                           |
| ---------- | ------------------------------------- |
| SCRUM-6    | Inicialización de estructura y README |
| SCRUM-7    | Desarrollo del script de análisis     |
| SCRUM-8    | Revisión, documentación y cierre      |

## Ejecución

```bash
python scripts/analisis.py
```
