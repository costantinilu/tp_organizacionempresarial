# Análisis de Ventas - Empresa Simulada

## Integrante
- Luciano Costantini

## Escenario elegido
Escenario B – Análisis de Ventas de una Pequeña Empresa

## Descripción del proyecto
Este proyecto implementa un flujo de trabajo ágil utilizando GitHub, GitHub Flow, Jira y Google Colab para gestionar el desarrollo de un script de análisis de datos de ventas.

## Descripción del dataset
El dataset contiene información de ventas con las siguientes columnas:
- producto
- cantidad
- precio
- fecha

- Planificación de tareas en Jira

- Pull Request y revisión

## Evidencias de trazabilidad
| Tarea Jira | Descripción |
|------------|-------------|
| SCRUM-6 | Inicialización de estructura y README |
| SCRUM-7 | Desarrollo del script de análisis |
| SCRUM-8 | Revisión, documentación y cierre |

## Instrucciones de ejecución

1. Ejecutar el entorno en Google Colab o local
2. Instalar dependencias:
   pip install pandas matplotlib

3. Ejecutar el script:
   python scripts/analisis.py

4. Los resultados se generan en la carpeta /resultados
